\# Window Backup Helper



\## What problem does this solve?



The tool backup all my files of two folders which stores all files inside of it. if it goes missing then i copy it backup folder of what it contains.



\## What do i need?



* laptop
* Window 11
* File Explorer
* Command prompt
* A browser
* GitHub 







\## How do i run it?



Double click on back.up  to run and see the message. Then i go back to backup folder to see if the files are there copied. i use command keys copied from practice-files previously which contain texts files and paste in backup folder.





\## How do I restore a file?



1. Rename  the file name tasks.txt to tasks-missing.txt inside practice-file folder.
2. Then in backup folder copy the tasks.txt
3. Check for restore contents and open the tasks.txt
4. Delete extra tasks-missing.txt after checking.
